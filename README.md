# Task Management System

A beginner-friendly task management application built with HTML, CSS, and JavaScript.

## Features

- Create tasks with titles and descriptions
- Set task priorities
- Edit and delete tasks
- Mark tasks as completed or pending
- Search tasks by title
- Filter tasks by status
- View task statistics
- Save tasks using browser LocalStorage

## Technologies Used

- HTML
- CSS
- JavaScript
- LocalStorage

## Data Storage

Tasks are saved in the browser's LocalStorage.
Clearing the browser's site data may remove saved tasks.
